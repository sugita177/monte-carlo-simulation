# Model 03: 2次元パーコレーション問題 (Percolation Transition)

## 1. モデルの定義と数理構造

### パーコレーションとは
パーコレーション（Percolation: 浸透問題）は、統計力学において**「幾何学的相転移（Geometric Phase Transition）」**のプロトタイプとして最も広く研究されている確率幾何モデルです。
磁性体におけるスピン間相互作用や温度 $T$ による熱ゆらぎではなく、**「接続確率（占有確率）$p$」** のみをパラメータとして、ミクロな局所的連結がマクロな大域的貫通（無限クラスターの創発）へと至る臨界現象を記述します。

### サイトパーコレーション (Site Percolation)
$L \times L$ の 2次元正方格子において、各サイト（格子点）は互いに独立に確率 $p \in [0, 1]$ で「占有（Occupied / Open）」され、確率 $1 - p$ で「空虚（Empty / Closed）」となります：

$$s_i = \begin{cases} 1 & (\text{確率 } p) \\ 0 & (\text{確率 } 1 - p) \end{cases}$$

- 最隣接（上下左右）の占有サイト同士が接続しているとき、それらは同一の**「クラスター（連結成分）」**を形成します。

### ボンドパーコレーション (Bond Percolation)
格子点はすべて存在し、格子点間の各ボンド（辺）が確率 $p$ で接続されるモデルです。
正方格子において自己双対性を持ち、厳密に $p_c = 1/2$ であることが知られています。
（本プロジェクトでは、より一般性がありクラスター構造が豊かな **サイトパーコレーション** を主対象とします）

### 2次元正方格子の臨界確率
- **サイトパーコレーション**: $p_c \approx 0.592746$（厳密解はなく、数値解析による高精度解）
- **ボンドパーコレーション**: $p_c = 0.5$（厳密解）

## 2. 幾何学的相転移と臨界現象

占有確率 $p$ を $0$ から $1$ へと増加させたとき、系は臨界点 $p_c$ を境に劇的な相転移を起こします：

```text
占有確率 p:  0 ----------------------- p_c (≈ 0.5927) ----------------------- 1
相:          非浸透相 (Non-Percolating)  臨界点 (Critical)      浸透相 (Percolating)
クラスター:   小さな有限孤立クラスター群   フラクタル無限クラスター   系全体を覆う巨大海
浸透確率:     Π(p) = 0                   0 < Π(p_c) < 1         Π(p) = 1
秩序変数:     P_∞(p) = 0                 P_∞(p) ~ (p - p_c)^β   P_∞(p) > 0
相関長:       ξ(p) < ∞                   ξ(p) -> ∞ (相関長発散)  ξ(p) < ∞
```

### 臨界指数と普遍性 (Universality)
パーコレーションの臨界現象は、格子幾何（正方格子、三角格子、ハニカム格子）の微視的詳細に依らず、**空間次元 $d=2$ のみで決まる普遍的な臨界指数**に従います：

1. **秩序変数（浸透強度） $P_\infty(p)$**:
   全サイト（または全占有サイト）のうち、無限クラスターに属する割合：
   $$P_\infty(p) \propto (p - p_c)^\beta \quad (p > p_c), \quad \beta = \frac{5}{36} \approx 0.1389$$
2. **平均有限クラスターサイズ $S(p)$**（磁化率 $\chi$ に相当）:
   無限クラスターを除いた、有限クラスターの平均サイズ：
   $$S(p) \propto |p - p_c|^{-\gamma}, \quad \gamma = \frac{43}{18} \approx 2.3889$$
3. **相関長（連結長） $\xi(p)$**:
   同一クラスターに属する 2 点間の平均空間距離：
   $$\xi(p) \propto |p - p_c|^{-\nu}, \quad \nu = \frac{4}{3} \approx 1.3333$$
4. **臨界クラスターのフラクタル次元 $D_f$**:
   臨界点 $p = p_c$ におけるパーコレーションクラスターは自己相似（フラクタル）構造を持ちます：
   $$M(R) \propto R^{D_f}, \quad D_f = d - \frac{\beta}{\nu} = 2 - \frac{5/36}{4/3} = \frac{91}{48} \approx 1.8958$$

## 3. 高速アルゴリズム：Hoshen-Kopelman (HK) 法 と Union-Find

パーコレーションの研究における計算上の最大の課題は、**「$L \times L$ 個のサイトから連結クラスターを高速に検出し、ラベル付けすること」** です。単純な幅優先探索 (BFS) や深さ優先探索 (DFS) でも $O(N)$ ですが、定数倍が重く、再帰の深さやメモリ消費が問題となります。

### Hoshen-Kopelman 法
Hoshen と Kopelman (1976) によって提案された、格子を一巡走査しながら **Disjoint-Set (Union-Find)** 木構造を用いてクラスターを動的にマージする画期的なアルゴリズムです。

1. 格子をラスタ走査（左から右、上から下）する。
2. 占有サイト $(r, c)$ に対し、「左隣 $(r, c-1)$」と「上隣 $(r-1, c)$」のラベルを調べる：
   - 両方とも空: 新しいクラスター番号を発行。
   - 片方のみ占有: その隣接サイトのラベルを継承。
   - 両方とも占有:
     - ラベルが同じならそのまま継承。
     - ラベルが異なる場合、2つの異なるクラスターがこのサイトを介して連結したことを意味するため、**Union-Find 木で 2 つのラベルを統合（Union）** する。
3. 経路圧縮（Path Compression）により、木の探索コストは実質 $O(1)$（アッカーマン関数の逆関数 $\alpha(N)$）となり、極めて高速に動作します。

## 4. 観測すべき物理量

1. **貫通確率 (Percolation Probability) $\Pi(p, L)$**:
   系の上端から下端（垂直貫通）、または左端から右端（水平貫通）へ繋がるクラスターが存在する確率（サンプリング試行の割合）：
   - $p < p_c$: $\Pi(p) \to 0$ ($L \to \infty$)
   - $p > p_c$: $\Pi(p) \to 1$ ($L \to \infty$)
   - 異なる $L$ の $\Pi(p, L)$ 曲線は、臨界点 $p_c$ でほぼ 1 点で交差するため、臨界確率 $p_c$ の高精度決定に用いられます。
2. **最大クラスター比率 $P_{\max}(p)$**:
   最大クラスターのサイズ $S_{\max}$ を全サイト数 $N = L^2$（または占有サイト数 $N_{\mathrm{occ}}$）で割った値。
3. **平均有限クラスターサイズ $S(p)$**:
   最大クラスター（無限クラスター候補）を除外した有限クラスター群の平均サイズ：
   $$S(p) = \frac{\sum_{s \neq s_{\max}} s^2 n_s}{\sum_{s \neq s_{\max}} s n_s}$$
   臨界点 $p = p_c$ で発散ピークを示します。
4. **クラスターサイズ分布 $n_s(p)$**:
   サイズ $s$ のクラスターの個数分布。臨界点ではべき乗則 $n_s(p_c) \sim s^{-\tau}$（$\tau = 1 + d/D_f = 187/91 \approx 2.05$）に従います。

## 5. ディレクトリ構成と設計方針

本モデルも、高速な Union-Find / HK クラスター検出エンジンを Rust (`crates/mc_core`) で実装し、PyO3 経由で Python から制御・可視化します。

```text
monte-carlo-simulation/
├── crates/mc_core/                 # 高速シミュレーションエンジン (Rust)
│   ├── Cargo.toml
│   ├── src/
│   │   ├── lib.rs
│   │   ├── percolation_2d.rs       # 2D パーコレーション・HK法・Union-Find
│   │   └── ...
│   └── tests/
│       ├── test_percolation_2d.rs  # Rust 単体テスト (p=0, 1 極限, 連結性判定)
│       └── ...
│
└── models/model_03_percolation/    # パーコレーション解析・可視化 (Python)
    ├── README.md                   # 本ドキュメント（理論・アルゴリズム・実験手順）
    ├── src/
    │   ├── __init__.py
    │   ├── simulation.py           # パーコレーション生成・アンサンブル計測
    │   ├── observables.py          # 物理量集計 (貫通確率, P_∞, 平均サイズ, 分布)
    │   ├── plot_percolation.py     # 臨界確率 p_c & 幾何学的相転移プロット
    │   └── animate_percolation.py  # p スイープに伴うクラスター成長アニメーション
    ├── tests/
    │   ├── __init__.py
    │   └── test_percolation.py     # Python 統合テスト
    └── outputs/                    # 解析結果プロット・GIF保存先
```
